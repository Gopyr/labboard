# Lab Board

GP-1 Lab Board is a visual dashboard and automated delta analyzer for GP-1 benchmark reports. It runs 100% in-browser with zero external charting dependencies, featuring local JSON parsing and CSV comparison export.

## Features

- **In-Browser Visualization**: Instant SVG bar chart rendering of benchmark metrics (requests, throughput, latency percentiles).
- **Automated Delta & Regression Analysis**: Compare Report A and Report B side by side to instantly spot performance regressions.
- **CSV Export**: Export comparison metrics directly to CSV for offline analysis and documentation.
- **Zero Dependencies**: Pure React + Vite + browser FileReader. No data leaves your machine.

## Quick Start

```bash
npm install
npm run dev
```
